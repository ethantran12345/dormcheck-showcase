# Design system

- **Brand:** primary color `#03C03C` (= `malachite-600` = `dormcheck.brand` token); font Nunito via `font-sans`. Default card = `rounded-card border border-stone-200 bg-white shadow-raised hover:shadow-overlay`.
- **Shape + elevation tiers (Phase 1.8) — pick by ROLE, not size.** Radius: `rounded-control` (12, buttons/inputs/selects) · `rounded-card` (16, default container) · `rounded-editorial` (24, page-like hero/statement surfaces) · `rounded-pill` (the only legit full-round: badges/chips/avatars/toggles). Elevation: `shadow-flat` (no shadow, hairline `border-stone-200` — a decorative ~1.1:1 boundary, so don't rely on it alone where a boundary is *essential*) · `shadow-raised` (default lifted card) · `shadow-overlay` (dialogs, popovers, floating menus). Light shadows are warm (`--shadow-color`, stone hue 26) — never re-introduce cool slate in a shadow. **Banned & gated** by `npm run lint:colors`: bare Tailwind `shadow-sm|md|lg|xl` (RULE 4) and arbitrary `rounded-[Npx]` (RULE 5); residue grandfathered in `scripts/shape-baseline.json` (debt — shrink it). Token/tier source: `src/design/tokens.json` + `tailwind.config.ts`.
- **Palette:** the full 11-shade Malachite scale (`malachite-50`…`950`) is the main app palette, defined in **`src/design/tokens.json`** (canonical token source → Tailwind + Figma; themed colors also as `hsl(var(--token))` in `src/index.css`). **Never hard-code a green hex** — reach for the nearest `malachite-*` step. Full token flow: `docs/design-tokens.md`.
- **Literal font sizes follow the documented ramp** (2026-08-04). `text-[Npx]` must use a step from `src/design/tokens.json` → `typography.scale`: **9, 10, 11, 12, 13, 15, 17, 19, 20, 26, 28, 30, 34**. Tailwind's named steps (`text-sm`…) and the clamp-driven marketing sizes (`TYPE.*` in `src/components/marketing/landing/tokens.ts`) are separate systems and unaffected. Off-ramp values (`text-[14.5px]`…) are DRIFT, ratcheted per file by `npm run lint:colors` RULE 7 against `scripts/type-baseline.json` — fails on growth only; list sites with `node scripts/check-colors.mjs --report-type`. **Adding a step means editing `typography.scale` AND the `typography:` block in root `DESIGN.md` in the same pass** — the gate reads the first, the impeccable design hook parses the second, and skipping either makes them disagree. Rationale: `docs/design-tokens.md` § "The literal type ramp".
- **Neutral = warm `stone-*`, never cool `slate/zinc/gray/neutral`.** The text/border neutral is the DormCheck warm-gray `stone-*` scale (`tokens.json`, overrides Tailwind's built-in cool stone). Tailwind's built-in `slate-|zinc-|gray-|neutral-<shade>` classes are **banned** and so are NEW raw hex colors — both enforced by the blocking **`npm run lint:colors`** gate (`scripts/check-colors.mjs`, in dev-push CI). Pre-existing hex is grandfathered in `scripts/color-baseline.json` (debt — shrink it, don't grow it); genuinely color-data files (mapbox/transit/pins/theme-color) are glob-exempt. The brand token `dormcheck-slate` (no shade) is unaffected.
- **Accessibility (WCAG 2.1 AA, standing bar):** every input/button/icon control needs a real accessible name. Solid `#03C03C` fails AA for white text — use **`malachite-800`** for solid green buttons/interactive fills; `#03C03C` stays the brand accent everywhere else (icons, checkmarks, logo). One `<main id="main-content">` per layout; keyboard-operable; respect `prefers-reduced-motion`; never block pinch-zoom in the WKWebView. `jsx-a11y` (lint) and axe (`audit:app`, `A11Y_STRICT=1`) are required gates — fix regressions, don't downgrade them. Detail: `docs/audits/accessibility.md`.
- **Components:** shadcn/ui from `@/components/ui/` first; search `src/components/` and reuse before building. Design-sync internals (claude.ai/design bundle): read `.design-sync/NOTES.md` before any re-sync.
- **Surfaces:** unprefixed Tailwind is the mobile/iOS baseline; add desktop overrides with `md:`/`lg:` only — never change unprefixed classes to serve desktop. Branch runtime behavior on `Capacitor.isNativePlatform()` (shell) and `useIsMobile()` (768px, responsive web).
